# Balloon Safaris Finance

Finance management showcase for Balloon Safaris (React + TypeScript + Vite).

## Live demo

https://olgar162001.github.io/balloon-Safaris/

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages

Pushing to `main` builds and deploys via `.github/workflows/deploy.yml`.

If the site is not live yet, open the repo **Settings → Pages**, set **Source** to **GitHub Actions**, then re-run the **Deploy GitHub Pages** workflow.
