# Balloon Safaris Finance

Finance management showcase for Balloon Safaris (React + TypeScript + Vite).

## Live demo

https://olgar162001.github.io/balloon-Safaris/

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages setup (required)

This project deploys with **GitHub Actions**, not a branch folder.

1. Open [Settings → Pages](https://github.com/olgar162001/balloon-Safaris/settings/pages)
2. Under **Build and deployment → Source**, choose **GitHub Actions**
3. Open [Actions](https://github.com/olgar162001/balloon-Safaris/actions) → **Deploy GitHub Pages**
4. If asked, click **Run workflow** (or wait for the latest run to finish)
5. If the deploy job is waiting for approval, open it and click **Review deployments → Approve**
6. Hard refresh the site: `Ctrl+Shift+R`

Do not use "Deploy from a branch". That keeps serving a blank/cached page.
